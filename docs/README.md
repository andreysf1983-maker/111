# LegionForge 7.3.5 (build 26124) — сервер World of Warcraft

Исходный код серверной части Legion 7.3.5 (build 26124), SQL-скрипты и инструменты.
Код содержит поддержку кастомных client race ID 31–44; для неё требуются согласованные
ChrRaces/CharSections/CreatureDisplayInfo из конкретного клиента. Серверный пакет не
содержит клиента, клиентских файлов, извлечённых карт, MySQL-баз или готовых Windows EXE.

## Статус проверки — прочитайте до запуска

В этом архиве исправлены исходники и автоматические аудиторы проходят, но в среде сборки
не было MSVC/Visual Studio, CMake, Boost, MySQL, Windows PowerShell и клиентских данных.
Поэтому worldserver/bnetserver не были собраны и запущены, SQL не выполнялся на вашей базе,
а реальный вход клиентом в игровой мир не проверен. «Полностью играбельным» этот архив
можно назвать только после сборки и smoke-теста на целевой Windows-машине.

Почему так: в корне остаются только точки входа (.bat), а всё остальное разложено по
назначению. Все скрипты находят корень проекта сами, поэтому папку можно переносить целиком.

## Порядок запуска (для Windows)

1. `UNBLOCK.bat` — снимает блокировку Windows с файлов, скачанных из интернета (запускать один раз).
2. `setup.bat` — проверяет клиент, MySQL, создаёт `server/worldserver.conf` и `server/bnetserver.conf`
   из `*.conf.dist`, применяет SQL и создаёт администратора.
3. `extract_maps.bat` — один раз извлекает карты из папки клиента WoW 7.3.5 (maps, vmaps, mmaps).
4. `play.bat` — запускает серверы. Вход: логин `admin`, пароль `legionforge`, в клиенте выбрать
   реалм и нажать «Вход в мир».

Если сервер не запускается — смотрите `logs/` и `server/Logs/`, а также `server_status.bat`.

## Настройки серверов

* `server/worldserver.conf.dist` — 606 настроек игрового сервера, у каждой русская подсказка
  с описанием и значением по умолчанию.
* `server/bnetserver.conf.dist` — 40 настроек сервера авторизации Battle.net.

Значения в файлах не менялись: переведены только комментарии. Проверка: все рабочие строки
конфигов идентичны исходным (см. `tools/i18n/`).

Важные для кастомного клиента настройки (`worldserver.conf`):

| Настройка | Значение | Зачем |
|---|---|---|
| `CustomRaces.Enable` | 1 | Включает кастомные расы 31–44 |
| `CustomRaces.Definitions` | `31:HORDE:8,…` | Донор задаёт фракцию/стартовые данные; для некоторых ID заданы native display ID |
| `Login.StrictAppearance` | 0 | Принимать внешность кастомного клиента при входе |
| `Network.InstanceSocketFallback` | 1 | Не падать, если инстанс-сокет недоступен |

## Что исправлено (сводка)

| Жалоба / журнал | Что сделано |
|---|---|
| Новые расы не видны при создании (`Errors.txt`) | Союзные расы 27–30 и кастомные 31–44 разблокированы сразу, без достижений (`CharacterHandler.cpp`, `RaceUnlockData`) |
| Нельзя создать/войти кастомной расой | Внешность принимается в custom-client режиме; проверки сначала используют данные расы, а при их отсутствии — донор (`Player.cpp`) |
| Вылет при входе в мир / «Соединение разорвано (WOW51900319)» | Вместо кика — предупреждение в логе, если внешность не совпадает с серверным CharSections.db2 (`Login.StrictAppearance = 0`) |
| Неподдерживаемые BfA loot-эффекты | SQL `103` удаляет неверные шаблоны и отключает перечисленные спеллы; C++ отклоняет неизвестные эффекты целиком. Фальшивых дропов нет. |
| `DBErrors.log`: `areatrigger` spawn_mask | `101_legionforge_dberrors_fixes.sql` (DBE-10) |
| `lfg_dungeon_template` без проверенного входа | Не подтверждено как игровая ошибка/исправление; точный полный набор ID отсутствует в приложенных логах. Нельзя объявлять исправленным без клиента/БД. |
| SpellEffect ID выше Legion | Всё заклинание исключается из SpellInfo; фиктивного `EffectNULL` для ID 256–261 больше нет (`SpellMgr.cpp`) |
| Конфиги на английском | Все подсказки `*.conf.dist` переведены на русский |
| Корень проекта завален | Файлы разложены по папкам (см. выше) |

## Известные ограничения

* В `logs/DBErrors.log` есть предупреждения о C++ AreaTrigger-скриптах `at_legion_portal_*`, не связанных с ID в базе. В пакете нет `AreaTrigger.db2` и SQL-источника этих ID; эти телепорты **не считаются реализованными/проверенными**. Для полноценного исправления нужен конкретный клиент и извлечение DB2 до добавления привязок.
* Native display ID для кастомных рас задан в исходниках и зависит от сборки клиента. Без ваших DB2 невозможно подтвердить, что IDs 31–44 и модели UWOW совпадают; если не совпадают, расы необходимо отключить до добавления согласованных данных, а не подменять модель произвольным донором.
* Загрузка DB2 на слабом диске занимает до 2 минут — это нормально.
* Полная сборка ядра требует Visual Studio 2022, CMake, Boost, OpenSSL и MySQL (делает `build_server.bat`).

## Перевод конфигов

Скрипт `tools/i18n/build_conf_ru.py` переводит блоки комментариев по словарям
`tools/i18n/ru_*.py`. Чтобы добавить настройку, допишите её описание в словарь и запустите:

```
python tools/i18n/build_conf_ru.py server/worldserver.conf.dist server/worldserver.conf.dist tools/i18n/ru_world_all.py WORLD
```
